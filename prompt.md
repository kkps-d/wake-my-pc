Create an app to save, monitor, and wake computers on a local network.

- Add computers by IPv4 and MAC address, with an optional name that defaults to the IP address.
- Find MAC addresses from IP addresses when possible, with manual entry as a fallback.
- Validate addresses and reject duplicate IP or MAC addresses.
- Keep saved computers across restarts.
- Search computers by name, IP, or MAC address.
- Automatically check and display reachability, including checking, waking, and error states.
- Wake computers using Wake-on-LAN, prevent repeated requests while waking, and check until reachable or timed out.
- Confirm before removing a saved computer.
